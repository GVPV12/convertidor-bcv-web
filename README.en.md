# 💱 BCV Converter (web)

[Español](README.md) | **English**

Web version of the original Python/Kivy [Currency Converter](https://github.com/GVPV12/usdtoves).
Converts **US dollars (USD)** and **euros (EUR)** to **Venezuelan bolívars (VES)** and back, using the official rate from the **Central Bank of Venezuela (BCV)**.

## Features

- 🔄 USD/EUR → Bs and Bs → USD/EUR conversion, live as you type
- 📊 Today's BCV rate with a historical chart (7, 30 and 90 days) and percentage change
- 💶 Button to switch between dollar and euro
- 💬 A different quote of hope and motivation on every visit (38 quotes, in Spanish and English)
- 🌐 Spanish / English language
- 🎨 3 skins: **Fluid**, **Hologram** and **Emerald**, with options to rotate them automatically or pick a random one on start
- 👁️ Simple view: price only, no chart or percentage
- ✅ Optional **Verify** button linking to the official BCV website
- 💾 All settings are remembered when you come back
- 📴 When offline, it shows the last saved rate
- 📱 100% responsive: works on any device (phone, tablet, laptop and large monitors)

## Usage

🌐 **Live:** [usdbcv.netlify.app](https://usdbcv.netlify.app/)

No installation or build step: you can also just open `index.html` in your browser.
It is hosted on **Netlify**, which redeploys the site on every commit to `main`.

> 🔖 **Tip:** save it to your bookmarks (or your phone's home screen) and open it whenever you need to convert. It works just as well on any device.

## Data sources

| Data | Source |
|---|---|
| Today's rate (USD and EUR) | Read straight from the [bcv.org.ve](https://www.bcv.org.ve/) home page, with its **value date** |
| Chart history | [DolarApi Venezuela](https://dolarapi.com/docs/venezuela/) |
| Fallback rate | DolarApi, and when offline, the last rate saved in the browser |

How it stays up to date:

1. Every 30 minutes, the [`update-rates.yml`](.github/workflows/update-rates.yml) GitHub Action runs `scripts/update-rates.mjs`, which reads the BCV website.
2. If the rate or value date changed, it saves `rates.json` and commits it; Netlify publishes the change on its own.
3. The site reads `rates.json` and DolarApi in parallel and shows the most recent rate, so the new rate appears as soon as the BCV publishes it in the afternoon.

The script rejects any rate that jumps more than 25% from the previous one. The Action can also be run manually from the **Actions** tab → **Actualizar tasa BCV** → **Run workflow**.

## Tech

- Plain HTML, CSS and JavaScript, no build tools
- [Tailwind CSS](https://tailwindcss.com/) (CDN) for layout
- GitHub Actions + Node 20 (no dependencies) to read the BCV rate
